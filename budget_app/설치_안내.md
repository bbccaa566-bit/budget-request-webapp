# 예산 요구안 작성 웹앱 — 설치·사용 안내

> 내 PC에서만 동작하는 웹앱입니다. 자료를 외부로 보내지 않고, AI도 쓰지 않습니다.

## 1. 준비 (처음 한 번)

1. **Python 3** 설치 확인 — 명령 프롬프트에서 `python --version`
   - 없으면 python.org에서 설치 (설치 화면에서 "Add python.exe to PATH" 체크)
2. **openpyxl** 설치 — 명령 프롬프트에서:
   ```
   python -m pip install openpyxl
   ```
3. 아래 파일을 같은 폴더 구조로 복사
   ```
   (아무 폴더)/
   ├─ 예산요구안_작성.bat
   └─ budget_app/
      ├─ server.py
      ├─ budget_core.py
      └─ static/ (index.html, app.js, style.css, sample/ 연습용 샘플 2개)
   ```

## 2. 실행

- `예산요구안_작성.bat` **더블클릭** → 2초 뒤 브라우저가 열림 (`http://127.0.0.1:8789`)
- 검은 창을 닫으면 웹앱이 종료됩니다. 쓰는 동안은 열어 두세요.

## 3. 처음 쓰는 분

- 첫 화면의 **[샘플로 연습하기]** — 가상 샘플 엑셀·메모가 자동으로 들어갑니다. ①~④단계를 끝까지 연습해 보세요. 머리글에 '연습 모드'가 표시되며, 샘플 결과는 실제 요구안에 쓰지 않습니다.
- 머리글 오른쪽 **[도움말]** — 사용 순서, 산출방식 4가지, 산출 줄 쓰는 법, 용어, 자동 검사 설명.

## 4. 사용 순서

| 단계 | 할 일 |
|---|---|
| ① 자료 올리기 | 올해 예산·집행 엑셀(.xlsx)을 끌어다 놓기 → 요구 연도·집행 기준월·금액 단위 선택. **증감 사유 기준(%)**은 부서 기준에 맞춰 입력(비우면 증감이 있는 모든 사업). 사업계획 메모(.txt/.md)는 선택 |
| ② 열 맞추기 | 비목·세부사업·배정액·집행액 열이 맞는지 확인. 틀리면 드롭다운으로 지정 |
| ③ 산출 편집 | 사업마다 산출방식 선택 → '계획 산출'이면 **산출 줄**(항목·단가·수량·횟수·단위) 입력. 한 사업에 비용이 여러 가지면 [+ 산출 줄 추가]. 행을 누르면 아래에서 요구 사유·근거 자료·확인 필요 수정. 신규 사업은 [+ 신규 사업] |
| ④ 검사·내보내기 | 검사 7개가 모두 ✔이면 [엑셀 내려받기]. 사업별 요약 표에서 증감·사유 점검을 확인. 이어서 할 때는 [초안 저장(.json)] |

- 산출방식: **계획 산출**(산출 줄 합계) / **올해 집행액 기준**(집행액 그대로) / **계획 없음**(0) / **미산정**(금액 미정, 합계 제외)
- 산출 줄 예: `월 33,000 × 12개월` → 단가 33,000 · 수량 12 · 단위 개월 / `3회 × 12,000` → 단가 12,000 · 수량 1 · 횟수 3. 횟수를 비우면 1
- **증감 사유 점검(C7)**: 기준 이상 증감이거나 신규인 사업은 요구 사유가 비어 있으면 내보낼 수 없습니다. 자동 문구 그대로면 경고(⚠)만 나오니 구체적 사유를 덧붙이세요.
- 작성 중인 내용은 브라우저에 자동 저장됩니다. 다시 열면 "이어서 작성"이 나옵니다.
- 동료에게 넘길 때: [초안 저장] 파일 + (가능하면) 원본 엑셀을 함께 전달. 원본 없이 불러오면 "원본 파일 미대조" 경고가 붙습니다. 예전 버전에서 저장한 초안(.json)도 불러올 수 있습니다.

## 5. 결과 엑셀 (5시트)

| 시트 | 내용 |
|---|---|
| 요약 | 비목별 배정·요구·증감, 산출방식별 건수, 입력 자료·증감 사유 기준·검사 결과 |
| 사업별 요약 | 사업마다 배정·요구·증감·증감률·요구 사유·사유 점검 |
| 산출내역 | 사업마다 산출방식·요구액(수식)·산출 근거·요구 사유·근거 자료·확인 필요 |
| 산출 세부 | '계획 산출' 사업의 산출 줄(단가 × 수량 × 횟수) |
| 확인 필요 | 확인 필요가 있는 사업만 |

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 창이 바로 닫힘 / `python`을 찾을 수 없음 | 1단계 Python 설치·PATH 확인 |
| `No module named openpyxl` | `python -m pip install openpyxl` |
| "서버에 연결할 수 없습니다" | 검은 창이 켜져 있는지 확인, 없으면 .bat 다시 실행 |
| 8789 포트 사용 중 | 다른 프로그램이 같은 포트를 쓰는 경우. `server.py`의 `PORT`와 `.bat`의 8789를 같은 다른 번호로 변경 |
| 필수 열을 못 찾음 | ② 열 맞추기에서 머리글 행과 열을 직접 지정 |
| "앱 파일이 없습니다" | `budget_app/static/` 폴더(샘플 포함)를 빠짐없이 다시 복사 |

## 7. 보안

- 127.0.0.1(내 PC)에서만 접속됩니다. 다른 PC·사이트에서 오는 요청은 거부합니다.
- 업로드한 원본 파일은 읽기만 합니다. 결과는 새 엑셀 파일로 내려받습니다.
- 결과 엑셀의 금액은 모두 **초안**입니다. 담당자가 확인 후 확정합니다.
