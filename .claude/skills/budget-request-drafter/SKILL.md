# 내년 예산 요구안 초안·산출내역

특정 부서·사업에 묶이지 않은 **범용 스킬**이다. 어느 부서의 예산 자료든 같은 방식으로 처리한다.
작업 폴더에 `업무_맥락.md`·`AI활용_컨텍스트.md`가 있으면 먼저 읽는다.

## 반드시 지킬 규칙 (사용자 확정)

1. **원본 파일 수정 금지** — 입력 파일은 읽기만 한다. 결과는 `예산_결과/`에만 저장한다.
2. **추측 금지·출처 표시** — 자료에 없는 단가·수량·금액을 만들지 않는다. 모든 행에 근거 자료(파일명 > 위치)를 적는다.
3. **외부 전송 금지** — 메일 발송, 웹 검색, 외부 업로드를 하지 않는다.
4. **금액은 본인 확정** — 결과는 초안이다. 채팅에서도 금액을 확정된 것처럼 말하지 않는다.

## 입력

- 기본 입력 폴더: `예산_샘플자료/` (실제 자료면 사용자가 알려준 폴더)
- **올해 예산·집행 엑셀**: 비목 / 세부사업 / 배정액 / 집행액 / 비고
- **내년 사업계획 메모**: 내년에 할 일, 단가·수량(있는 경우), 신규 사업
- 금액 단위는 원본을 따른다(샘플은 천원). 단위가 섞여 있으면 멈추고 사용자에게 묻는다.
- HWP는 PDF로 저장해 달라고 요청한다.

## 산출 방식 결정 (행마다 하나)

| 산출방식 | 언제 | 단가 / 수량 / 단위 |
|---|---|---|
| `계획 산출` | 계획 메모에 단가와 수량이 모두 있음 | 메모 값 그대로 |
| `올해 집행액 기준` | 메모에 단가·수량이 없거나, 메모에 언급이 없음 (사용자 결정) | 단가 = 올해 집행액, 수량 = 1, 단위 = `식` |
| `계획 없음` | 메모에 "내년 계획 없음"이 명시됨 | 단가 0, 수량 1 |
| `미산정` | 신규 사업 등 올해 집행액도 없고 금액도 미정 | 단가·수량 비움 (요구액 빈칸) |

`올해 집행액 기준`·`계획 없음`·`미산정` 행은 모두 **확인 필요**에 이유를 적는다. 반드시 넣을 것:
- 올해 집행액이 연중 누계(예: 10월 말)이면 "연간 집행액 아님 — 연말 추정치 확인 필요"
- 메모에 언급이 없는 사업이면 "계획 메모에 언급 없음 — 내년 계속 여부 확인"
- 메모의 증가 요인(예: 협의 확대)이 있지만 금액이 없으면 그 요인을 적는다

## 처리 순서

1. 입력 파일을 모두 읽는다. 올해 엑셀의 모든 세부사업을 빠짐없이 행으로 만든다.
2. 계획 메모의 신규 사업도 행으로 추가한다(올해 배정·집행 0).
3. 행마다 위 표로 산출방식을 정하고, 산출 근거·요구 사유·근거 자료·확인 필요를 채운다.
4. 아래 JSON을 `예산_결과/요구안_데이터.json`으로 저장한다.
5. 스크립트로 엑셀을 만든다. `--source`로 올해 엑셀을 주면 세부사업 누락과 배정·집행액 불일치를 검사한다(불일치 시 실패).

```json
{
  "title": "2027년 예산 요구안 초안",
  "unit": "천원",
  "base_note": "올해 집행액은 2026년 10월 말 누계",
  "sources": ["파일명1", "파일명2"],
  "rows": [
    {
      "비목": "용역비", "세부사업": "업무시스템 유지보수", "산출방식": "계획 산출",
      "단가": 33000, "수량": 12, "단위": "개월",
      "2026 배정액": 360000, "2026 집행액": 300000,
      "산출 근거": "월 33,000 × 12개월", "요구 사유": "신규 기능 추가로 유지보수 범위 증가",
      "근거 자료": "파일명 > 절", "확인 필요": ""
    }
  ]
}
```

```bash
python -I .claude/skills/budget-request-drafter/scripts/make_budget_request.py 예산_결과/요구안_데이터.json 예산_결과/2027_예산요구안_초안_YYYYMMDD.xlsx --source "예산_샘플자료/[샘플]2026_예산집행현황.xlsx"
```

## 엑셀 구성 (스크립트가 만듦)

- **요약**: 비목별 2026 배정액·2027 요구액·증감·증감률·미산정 건수 (SUMIF 수식) + 합계
- **산출내역**: 요구액 = 단가 × 수량 (수식). 산출방식별 색 구분
- **확인 필요**: 확인 필요가 있는 행만 모음

## 결과 보고 (채팅)

- 엑셀 경로, 세부사업 수, 산출방식별 건수
- 요구액 합계와 증감은 "초안 기준 ○○천원 (확인 필요)"로 표현
- 미산정 사업과 가장 먼저 확인할 것 3개 이내
- 검사(`--source`) 결과
